I just upgraded my **AAPL Finance AI** project — an interactive market-intelligence dashboard built with **Streamlit, TensorFlow, PyTorch, FinBERT, and Yahoo Finance**.

The dashboard now combines:

• AAPL price data and technical indicators
• 10-day and 20-day moving averages
• Daily and five-day returns
• 20-day volatility
• Financial-news sentiment using FinBERT
• An LSTM-based next-day UP/DOWN direction signal
• Model confidence, methodology, and responsible-use messaging

I also improved the product experience with a cleaner dashboard layout, cached model resources, more resilient API handling, a clearer README, and better explanations of the project architecture and limitations.

This project was a hands-on exercise in connecting **time-series modeling, NLP, financial data, and user-focused product design** in one application.
